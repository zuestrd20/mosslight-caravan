# 苔光行囊 original vector art

All illustrations are original self-authored SVGs. No external image assets, fonts, trademarks, or copyrighted characters are used.

- `battle-forest.svg`: 1440×640 moonlit forest with lantern-lit caravan and open battle clearing.
- `battle-moonwood.svg`, `battle-deepwood.svg`: palette variants for later chapters.
- `hero-fox.svg`, `hero-mushroom.svg`, `hero-badger.svg`: transparent 320×360 characters.
- `enemy-sprout.svg`, `enemy-slime.svg`, `enemy-beetle.svg`: transparent 320×360 opponents.
- `boss-owl.svg`, `boss-stag.svg`, `boss-root.svg`: transparent 320×360 bosses.
- Item illustrations: 96×96 original inline SVGs bundled in `art.js` (standalone source variants retained in the development workspace).
- `lantern.svg`: the original brand mark.
- `art.js`: ES module with `icon(type, className?)`, `itemIcons`, `portraits`, `backgrounds`.

Palette: deep moss #17352f, pale cream #f1dfb8, dusty jade #82b4a1, amber #e5c67a, rosewood #a86765.
